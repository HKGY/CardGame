# 卡牌爬塔 · Demo

一个类《杀戮尖塔（Slay the Spire）》的单人卡牌 Roguelite **基底**：在地图上连续闯关，
打普通怪 / 精英 / 首领，逛商店、休息升级，攒金币和牌组。纯 HTML + 原生 JS，无需构建。

## 运行

直接用浏览器打开 `index.html`。或起本地静态服务器：

```bash
cd cardgame && python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 玩法

- 打开后先进入**开始菜单**（标题 + 背景故事），点「开始攀登」开局。
- 敌人**按层登场**：每层有专属/更强的守望者（共 6 普通 / 3 精英 / 3 首领），多样性随攀登提升。
- 在**地图**上点击发光节点前进：⚔️战斗　💀精英　🛒商店　🏕️休息　👑首领（首领前固定一个休息点）。
- **战斗**：每回合 3 能量、抽 5 张；看敌人头顶**意图**决定攻防；血量在整局中保留。
- 战斗胜利得**金币** + **三选一卡牌奖励**，并有概率掉落**塔罗牌**；精英 / 首领给更多更好。
- **塔罗牌**（消耗品，默认 3 格，取代药水）：20 张大阿卡纳各有奇效，按情境（战斗 / 地图）在塔罗栏点击使用，
  例如「死亡（全体 20 伤害）」「皇帝（直达 Boss）」「命运之轮（补满消耗栏）」。
- **休息点**：回血 或 锻造一张卡。**商店**：买卡 / 买塔罗牌 / 锻造卡 / 删牌（越删越贵）/ 治疗（初始 99 金币，卡价已下调）。
- **事件祭坛**（🔮 节点，随机其一）：升级锻造 / 锻造(给 3 级增益) / 复制 / 删牌 / 重铸（重掷词条）。
- 战斗奖励与商店的卡**都带词条**（无裸卡）；精英 / 首领的卡明显比小怪更强。
- **遗物**（被动，共 19 个）：精英掉 1、首领掉 2、商店卖 2，不可重复获得；
  效果各异——加属性、商店半价、致死免死、过量治疗、每回合额外能量/抽牌、卡牌数值翻倍等。
- 共 **3 层**：打败每层首领进入下一层，**后层敌人数值膨胀**，每场 **Boss 战后回满生命**；通关第 3 层胜利，血量归零失败。
- 可随时点顶栏「🂠 牌库」看牌组、「📖 百科」查所有词条 / 消耗品 / 遗物 / 敌人；顶栏还显示层数、生命、金币、消耗品、遗物。
- 攻击/受击/格挡/抽卡/金币/治疗/升级/胜负都有**音效**（即时合成）；点 🔊 可静音。

### 卡牌（词条 + 锻造）

两种基底卡：**打击**（6 伤害）、**防御**（5 格挡）。词条分**增益(buff)**与**减益(debuff)**，各带**分数**衡量强弱
（buff 正分、debuff 负分；明亮/过载等高分更稀有）。卡名格式 `增益打击(减益)+X`——增益排在前、减益用**括号**包在
基底之后、最后是**锻造上限 +X**（仅计 buff，起始卡 1）。各词条用不同颜色显示，1~3 级前加「更/最」、数值 ×2/×3。

**锻造一次 = 一个随机等级的增益 + 一个 1 级的减益。** 在休息 / 商店 / 升级祭坛 / 锻造祭坛锻造时**二选一**；
战斗中的「锻造 / 审判」、核融合炉、群星等为**自动锻造**（不二选）。掉落卡只带增益（无减益）。达到上限后无法再锻造。

- **增益（11）**：压制 / 中和 / 破碎（给敌人上易伤 / 虚弱 / 脆弱）、准备（力量 / 敏捷）、抽取、多重（+段数）、
  风怒、锻造、过载（数值翻倍）、重复（多次打出）、明亮（回能）。
- **减益（8）**：钝化（数值 -2）、破绽 / 乏力 / 朽盾（自身易伤 / 虚弱 / 脆弱）、怯懦 / 笨拙（-力量 / 敏捷）、
  漏能（-能量）、侵蚀（随机降级手牌）。

词条与分数都在 `js/data/affixes.js`，也可点「📖 百科 → 词条」查看。

## 目录结构

```
index.html              页面骨架（多个 .screen）+ 脚本加载顺序
css/style.css           样式
js/
├─ data/                ★ 改这里来调内容 / 数值
│  ├─ cards.js          基底卡 + cardStats（聚合词条→数值/效果）+ 初始牌组
│  ├─ affixes.js        词条数据（名称/颜色/机制/效果文字）
│  ├─ tarot.js          塔罗牌数据（20 张：情境 where + 效果 apply）
│  ├─ relics.js         遗物数据（19 个：被动钩子 battleStart/onTurnStart… 与字段）
│  ├─ config.js         参数：血量/金币/层数与数值膨胀/药水/地图/各档掉落词条
│  └─ enemies.js        普通/精英/首领敌人 + ENEMY_POOLS 分组
├─ engine/              纯逻辑，不碰 DOM
│  ├─ effects.js        效果处理器（damage/block/draw/strength/weak…，可扩展）
│  ├─ game.js           单场战斗状态机（由 Run 提供牌组与血量）
│  └─ run.js            一次爬塔：血量/金币/牌组/地图/商店/休息/奖励
└─ ui/
   ├─ sprites.js        角色贴图（内联 SVG）
   ├─ audio.js          战斗音效（Web Audio 即时合成，无音频文件）
   ├─ background.js     动态背景（canvas 漂浮余烬 + CSS 流动星云）
   ├─ render.js         战斗界面 + 输入 + 精灵动画（导出 cardFace 复用卡面）
   └─ screens.js        开始菜单/地图/奖励/商店/休息/事件/结算 各屏 + 顶栏 + 百科
js/main.js              入口/控制器：按 run.phase 路由各屏，编排战斗
```

所有模块挂在全局 `window.CG`，按 `index.html` 的顺序加载。

## 怎么改

- **平衡数值**：`js/data/config.js`（起始血量、各档金币区间、商店价格、地图行数、奖励升级权重）。
- **卡牌基础值**：`js/data/cards.js` 的 `BASE_CARDS`；**词条/颜色/机制**：`js/data/affixes.js`。
- **加敌人**：`js/data/enemies.js` 加一项并放进 `ENEMY_POOLS` 对应档位；招式复用效果系统，
  可选 `chooseMove(game, history)` 自定义 AI。
- **加敌人贴图**：`js/ui/sprites.js` 加一段 SVG（key 与敌人的 `sprite` 字段对应）。
- **加新效果**：`CG.Effects.register('thorns', (game, eff, source, target) => {...})`，卡牌与敌人招式都能用。

## 架构要点

- **Run（meta）与 Battle 分离**：`run.js` 持有跨战斗的持久状态；战斗 `game.js` 由 `new Game({deck, hp, maxHp, enemyId})`
  实例化，结束后 `run.finishBattle(win, hp)` 回收结果。引擎都不依赖 DOM，便于测试。
- **数据驱动**：卡牌/敌人/经济都是数据；地图与奖励由 `config.js` 的参数生成。
- **界面分屏**：`main.js` 按 `run.phase` 切换 `.screen`；战斗界面与跑图界面解耦，靠 `onChange` 回调刷新。
