# 卡牌爬塔 · Demo

一个类《杀戮尖塔（Slay the Spire）》的单人卡牌 Roguelite **基底**，融合《Noita》法杖思路：
**效果绑定在「宝石」上，宝石可镶进 / 卸下卡牌（法杖）的孔位**。在地图上连续闯关，
打普通怪 / 精英 / 首领，逛商店打理宝石，攒金币、宝石与法杖。纯 HTML + 原生 JS，无需构建，
**无任何图片 / 音频外部素材**（立绘与卡面皆内联 SVG / emoji，音效即时合成）。

## 运行

直接用浏览器打开 `index.html`（已做**移动端响应式适配**，手机竖屏可玩）。或起本地静态服务器：

```bash
cd cardgame && python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 测试

纯逻辑层（`js/data/` + `js/engine/`）有单元测试，用 Node 内置测试运行器（无第三方依赖）：

```bash
npm test           # = node --test test/*.test.js
```

`test/harness.js` 把浏览器风格的 `window.CG` 模块加载进一个 vm 上下文（`window` 即全局对象），
于是引擎/数据可在 Node 里直接被测；UI 层（依赖 DOM）不在单测范围。覆盖：宝石聚合到卡牌的
`cardStats`、镶嵌/卸下（卸下随机加 debuff）、宝石生成（小增益 / 强增益+减益）、商店经济、
事件祭坛、战斗结算（伤害/格挡/状态/穿刺/风怒/销毁）以及整局自动推进通关。

## 玩法

- 打开后先进入**开始菜单**（标题 + 背景故事），点「开始攀登」开局。
- 敌人**按层登场**：每层有专属/更强的守望者（共 6 普通 / 3 精英 / 3 首领），多样性随攀登提升。
- **地图＝《以撒的结合》式房间布局**：每层从中心**起点 🚩** 用 BFS 泛洪（同《以撒》的生成思路）长出一片相连的房间（相邻即有门、整体是树、**房间格尺寸固定**）。房型有：**宝藏房 🎁**（白送遗物）、**诅咒房 🩸**（耗血进入、换 **2 个随机商店货色**：宝石/法杖/塔罗/遗物）、**商店 🛒**、**祭坛 🔮**（宝石操作）、**小boss房 👹**（精英怪）、**普通房**（按概率藏敌，**只有一半藏敌房会在地图上露出 ⚔️**，另一半进门才知）、**首领房 👑**（最远死路，清掉即通向下一层）。用 **WASD / 方向键或点击**控制自机角色在相邻房间间走动，踩进未清的内容房即触发；**有战争迷雾——只看得到去过房间四邻的格子**。进入战斗时镜头会缩放到所在房间、战斗控件再从屏幕外飞入；**战斗界面左上角有本层的略缩地图**。
- **战斗**：每回合 3 能量、抽 5 张；看敌人头顶**意图**决定攻防；血量在整局中保留。
- 战斗胜利得**金币** + **三选一奖励**：宝石奖励改为**开启一个主题 booster pack**（点开后翻出 3 颗同主题宝石三选一），有时则是**空孔法杖**；另有概率掉落**塔罗牌**；精英 / 首领更多更好。
- **塔罗牌**（消耗品，默认 3 格，取代药水）：20+ 张大阿卡纳各有奇效，按情境（战斗 / 地图）在塔罗栏点击使用，
  例如「死亡（全体 20 伤害）」「皇帝（直达 Boss）」「命运之轮（补满消耗栏）」。
- **商店**（合并了篝火、出现更频繁）：买宝石 / **买 booster pack（三选一 50 金 / 五选一 110 金 / 五选二 170 金，买下开包挑同主题宝石）** / 买法杖 / 买塔罗 / 买遗物 / 删卡（越删越贵）/ **给卡 +1 孔** / **卸下宝石** / 治疗。
  **一切皆需花钱**；唯独**镶嵌宝石免费**（在顶栏「💎 宝石」工作台进行）。
- **事件祭坛**（🔮 节点，随机其一，全为宝石主题）：镶嵌（免费装一颗）/ 净化（移除宝石一个减益）/ 拓孔（卡 +1 孔）/ 寻宝（得一颗宝石）/ 重铸（重掷宝石词条）。
- **遗物**（被动，共 47 个，多数借鉴《以撒的结合》）：精英掉 1、首领掉 2、商店卖 2，不可重复获得；
  效果各异——攻击加成、受伤减免、荆棘反伤、圣盾免疫、家族每回合攻击、最大能量+1、满血复活、消耗品栏+1、商店半价等。
- 共 **3 层**：每层一张以撒式房间布局，自由探索后清掉**首领房**进入下一层，**后层敌人数值膨胀**，每场 **Boss 战后回满生命**；通关第 3 层首领胜利，血量归零失败。
- 可随时点顶栏「💎 宝石」打理镶嵌、「🂠 牌库」看牌组、「📖 百科」查所有词条 / 消耗品 / 遗物 / 敌人；顶栏还显示层数、生命、金币、消耗品、遗物。
- 攻击/受击/格挡/抽卡/金币/治疗/胜负都有**音效**（Web Audio 即时合成，**无音频文件**）；点 🔊 可静音。

### 卡牌（法杖）+ 宝石 —— 借鉴《Noita》

效果不再绑定在卡牌上，而是绑定在**宝石**上。**卡牌 = 法杖**：有若干**孔位**，基底决定基础数值
（**打击** 6 伤害 / **防御** 5 格挡）与贴图。**宝石**带若干**增益(buff)**与**减益(debuff)**，镶进孔位后对该卡生效。

卡名格式 `打击(增益+减益)(增益)◇`——基底之后每颗宝石一组**括号**（增益在前、减益在后），末尾 `◇` 表示**空孔**。
各词条按**分数**衡量强弱（buff 正分、debuff 负分；明亮/过载等高分更稀有），不同颜色显示，1~3 级前加「更/最」、数值 ×2/×3。

**一颗宝石**：引擎支持多个正/负词条，但实践中要么是**「小增益」**（1 个朴素增益），要么是**「强增益 + 减益」**。
**镶嵌免费**（顶栏工作台）；**卸下要花钱，且宝石会随机多一个减益**——所以搬动宝石是有代价的取舍。

- **增益（36）**：压制 / 中和 / 破碎、准备、抽取、多重、风怒、过载、重复、明亮；借鉴《炉石》《宝可梦》的——
  吸血、淬毒（中毒，每回合受伤）、冰封（冻结跳过行动）、沉默（移除敌人力量）、回春、速记（-耗能）、穿刺、再生、荆棘；
  booster pack 新增的——**回响**（打出后下一张牌免费）、**壁垒**（获得格挡）、**连击**（本回合每打出过一张牌追加伤害）、**滋养**（治疗效率 +50%/层，本场持续）；
  元素附着——**附火 / 附水 / 附雷 / 附冰**（命中给敌人挂元素，叠加触发反应）；厨艺 give 词条——**农场 / 牧场 / 市场 / 厨房**（打出后送对应食材卡）；
  消耗系——**灰烬**（数值 +消耗堆数 ×等级）、**燃烧**（选并消耗 1 张手牌）、**涅槃**（被消耗时再打 1 次）、**不坏**（被消耗时生成副本）、**重生**（从消耗堆取回 1 张）。
- **减益（16）**：钝化（数值 -2）、破绽 / 乏力 / 朽盾（自身易伤 / 虚弱 / 脆弱）、怯懦 / 笨拙（-力量 / 敏捷）、
  漏能、笨重（+耗能）、反噬（-生命）、销毁（打出后移除）；厨艺腐坏——**腐败 / 变质 / 发霉**（塞给你馊饭 / 臭肉 / 烂菜）；
  消耗系——**爆燃**（消耗其余手牌）、**着火**（自身灼伤 2：每回合受伤、可被格挡）、**噩梦**（用渣滓塞满手牌）。

**Booster pack（词条分类）**：词条按主题分成 8 个包——🎴 基础 / ⚔️ 强攻 / ☠️ 诅咒 / 🌀 节奏（抽牌·能量·费用）/ 🌿 生机（治疗·续航·反伤）/ ⚗️ 元素 / 🍳 厨艺 / 🔥 消耗。
战斗后开到的是「一个包」，包内宝石的词条只来自该主题；商店 / 祭坛等其它产出的宝石也按包生成（基础包做通用兜底）。
**每局开局随机启用「基础包 + 3 个随机增强包」（共 4 个，其余增强包本局不出）**，所以每局的宝石取向都不同。详见「📖 百科 → 卡包」（标注本局启用/未启用）。

**元素反应**（⚗️ 元素包）：敌人身上至多挂 1 种元素、**层数 1~3**（火/水/雷/冰，附着层数=词条等级，不随回合衰减）。
再附一种异元素＝**消耗 min(双方层数) 级、反应发生这么多次、余量留在层数多的一方**（同元素则叠加，封顶 3）——
🔥+💧/❄️=**蒸发/融化**（本击 ×1.5^消耗层数）、🔥+⚡=**超载**（每级 10 穿透伤害）、💧+⚡=**感电**（中毒）、💧+❄️=**冻结**、⚡+❄️=**超导**（易伤）。
连招需两张不同元素的牌按序打同一敌人，建议在商店「**五选二**」一次拿 2 颗凑齐。

**厨艺包（🍳 做菜流派）**：增益（农场/牧场/市场/厨房）打出后会**送你食材卡**（素菜/荤菜/调味料/厨具，仅本场进手牌），减益（腐败/变质/发霉）则塞给你**腐坏卡**（馊饭/臭肉/烂菜：不能打出，回合结束自伤/虚弱/易伤后消失）。
**做菜**：打出**素菜**（番茄/土豆/胡萝卜，等级 1/2/3）→ 选一张**荤菜**（鱼/鸡/牛肉，可跳过）→ 选一张**调味料**（可跳过）→ 做成一张 **0 费、打出即消耗的「餐点」** 进手牌，择机打出发挥效果。
菜谱「素菜炖荤菜」的效果种类见矩阵（如牛肉×胡萝卜＝回响、鸡肉×土豆＝壁垒…），**数值 = 素菜等级 × 荤菜等级 × 2**；调味料修正：**盐**＝过载（数值 ×2）、**酱油**＝给餐点附「**滋养**」（治疗效率 +50%、本场持续，且本餐治疗也享受；滋养同时作为词条收入 🌿 生机包）、**胡椒**＝重复（结算 2 次）。**厨具**（菜刀攻5 / 铁锅防4 / 火炉附火2）是 **0 费**、可直接打出的武器。

**消耗包（🔥 玩「消耗」）**：增益让你榨干「消耗」机制——**灰烬**随消耗堆变强、**燃烧**主动消耗手牌、**重生**从消耗堆捞牌回手；尤其 **涅槃**（被消耗时再打一次）/**不坏**（被消耗时留副本）配合 **销毁**词条很强。减益是火上浇油——**爆燃**烧光手牌、**着火**给自己上 **灼伤**（新状态：和中毒一样每回合受伤、逐回合 -1，**但可被格挡**）、**噩梦**用 **渣滓**（1 费、打出即消耗、无效果）把手牌塞满（上限 10 张）。

词条与分数都在 `js/data/affixes.js`（含 `CG.PACKS` 分类）、宝石/食材/菜谱逻辑在 `js/data/cards.js`，也可点「📖 百科 → 词条 / 卡包」查看。

```
index.html              页面骨架（多个 .screen）+ 脚本加载顺序
css/style.css           样式
js/
├─ data/                ★ 改这里来调内容 / 数值
│  ├─ cards.js          法杖基底 + 宝石/孔位 + cardStats（聚合宝石词条→数值/效果）+ 初始牌组
│  ├─ affixes.js        词条数据（名称/颜色/机制/效果文字）——被打包进宝石
│  ├─ tarot.js          塔罗牌数据（情境 where + 效果 apply）
│  ├─ relics.js         遗物数据（47 个：钩子 battleStart/onTurnStart/onPlayerDamaged… 与字段）
│  ├─ config.js         参数：血量/金币/层数与数值膨胀/地图/宝石生成/商店价格
│  └─ enemies.js        普通/精英/首领敌人 + ENEMY_POOLS 分组
├─ engine/              纯逻辑，不碰 DOM
│  ├─ effects.js        效果处理器（damage/block/draw/strength/weak…，可扩展）
│  ├─ game.js           单场战斗状态机（由 Run 提供牌组与血量）
│  └─ run.js            一次爬塔：血量/金币/牌组/宝石背包/地图/商店/事件/奖励
└─ ui/
   ├─ sprites.js        角色贴图（纯内联 SVG，无图片）
   ├─ audio.js          战斗音效（Web Audio 即时合成，无音频文件）
   ├─ background.js     动态背景（canvas 漂浮余烬 + 纯 CSS 场景渐变/星云，无图片）
   ├─ music.js          （已停用：原 mp3 背景音乐移除，保留空接口）
```

## 怎么改

- **平衡数值**：`js/data/config.js`（起始血量、各档金币区间、商店价格、`map`（网格/房间数/藏敌率/明示率 telegraphChance/特殊房 extra）、`curse` 耗血、宝石生成权重、`packW` 选包权重）。
- **地图布局**：`js/engine/run.js` 的 `genIsaacFloor`（以撒式 BFS 泛洪生成，参考 [boristhebrave 的解析](https://www.boristhebrave.com/2020/09/12/dungeon-generation-in-binding-of-isaac/)）；渲染 / WASD / 进战斗演出在 `js/ui/screens.js`（`showMap` / `zoomMapToRoom` / `playBattleEntrance`）。
- **卡牌基底**：`js/data/cards.js` 的 `BASE_CARDS`；**宝石生成规则**同文件 `rollGem` / `pickPack`；**词条/颜色/机制**：`js/data/affixes.js`；**卡包分类**：`affixes.js` 的 `CG.PACKS`（选包权重 `config.js` 的 `packW`）。
- **加敌人**：`js/data/enemies.js` 加一项并放进 `ENEMY_POOLS` 对应档位；招式复用效果系统，
  可选 `chooseMove(game, history)` 自定义 AI。
- **加敌人贴图**：`js/ui/sprites.js` 加一段 SVG（key 与敌人的 `sprite` 字段对应）。
- **加新效果**：`CG.Effects.register('thorns', (game, eff, source, target) => {...})`，卡牌与敌人招式都能用。

## 架构要点

- **Run（meta）与 Battle 分离**：`run.js` 持有跨战斗的持久状态；战斗 `game.js` 由 `new Game({deck, hp, maxHp, enemyId})`
  实例化，结束后 `run.finishBattle(win, hp)` 回收结果。引擎都不依赖 DOM，便于测试。
- **数据驱动**：卡牌/敌人/经济都是数据；地图与奖励由 `config.js` 的参数生成。
- **界面分屏**：`main.js` 按 `run.phase` 切换 `.screen`；战斗界面与跑图界面解耦，靠 `onChange` 回调刷新。
